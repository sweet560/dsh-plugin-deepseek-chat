# dsh-plugin-deepseek-chat v1.1.1

**DeepSeek Chat panel for DeepSeek Harness Desktop — stable login session, DSH account status, and full ASAR integrity support for the restart-free login patch.**

- Requires DSH Desktop **0.2.2-rc.1** or newer.
- Requires Node >= 24 (Node 24 Active LTS).

## What's fixed

- **No more QR scan on every panel/session switch.** The guest partition is now a
  fixed constant (`panel:deepseek-chat`) instead of being derived from the async
  DSH account probe. DSH caches one session per workspace string for the process
  lifetime, so a stable string preserves the chat login.
- The DSH account state strip is display-only and never rebuilds the guest.
- The guest starts immediately, without waiting for the account Remote.

## Restart-free login (the important part)

DSH `0.2.1-rc.3+` (including `0.2.2-rc.1`) records a SHA256 **integrity** for
every file in `app.asar`. A byte-only replacement of the in-memory partition name
would crash DSH on restart with "ASAR Integrity Violation".

This release ships `scripts/patch-dsh-persistent-partition.cjs` (from upstream),
which:

1. Replaces `dsh-sidebar-browser-${randomUUID()}` with the equal-length
   `persist:dsh-sidebar-browser-chat-v1`;
2. Recomputes `lib/main.js`'s SHA256 and syncs the ASAR header `hash`/`blocks`;
3. Verifies every file/block hash before and after writing (verified on
   0.2.2-rc.1: **20519 files, 0 failures**);
4. Creates a timestamped backup and supports `--dry-run` and idempotent reruns.

```powershell
# Exit DSH completely from the tray first!
node scripts/patch-dsh-persistent-partition.cjs "F:\DeepSeek Harness\resources\app.asar" --dry-run
node scripts/patch-dsh-persistent-partition.cjs "F:\DeepSeek Harness\resources\app.asar"
# Restart DSH, sign in to chat.deepseek.com ONCE, then restart again — no more scans.
```

See [docs/login-persistence.md](docs/login-persistence.md) for the full
procedure, rollback, and per-platform paths.

## Honest limitation

A pure plugin still **cannot** make the web chat reuse the already-signed-in DSH
account: DSH uses a Platform `x-dsh-auth-token`, `chat.deepseek.com` uses its own
Token, the renderer bridge exposes no token/cookie API, and there is no official
SSO/exchange. One manual sign-in is required; the patch then keeps that session
permanently.
